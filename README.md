A deterministic Python program that draws a studio catalogue photograph of an impossible gadget: the POCKET NIMBUS, a hand-held personal rain cloud, caught mid-use as it waters exactly one houseplant. Pure standard library (zlib PNG encoder, embedded bitmap font, procedural raster shading); no network; two runs produce identical bytes.

## Run it

```sh
python3 main.py
```
